## Что измерялось

Quissly v1.0 — внешний набор товарного поиска на семи каталогах. Релиз датирован 22 июля 2026 года в CITATION.cff. Использован коммит a4b56b2732a00e7baac67444b38b0fdf4a65d308 от 23 июля. В семи сжатых JSON-файлах каждая запись содержит запрос и списки попаданий по провайдерам, включая ID товара, название, оценку, численный вес и объяснение. Запросы сгенерировал Gemini 2.5 Pro, релевантность оценивал Gemini 3.5 Flash. Судья мог видеть описание, цену и изображение, переранжировщик видел только запрос и название. Четыре каталога восходят к Amazon Reviews 2023, поэтому пересечение товаров с ESCI возможно. [Снимок Quissly](https://github.com/quissly/search-benchmark/tree/a4b56b2732a00e7baac67444b38b0fdf4a65d308) · [Описание источников каталогов](https://github.com/quissly/search-benchmark/blob/a4b56b2732a00e7baac67444b38b0fdf4a65d308/DATA_LICENSES.md).

Пул каждого запроса образуют уникальные размеченные товары из выдач пяти движков. BM25 ранжирует этот пул по названиям. Все три политики получают префиксы одного top-20. Знаменатель nDCG@10 использует десять лучших оценок полного доступного пула. Линейные веса Exact, Substitute, Complementary и Irrelevant равны 1, 0,1, 0,01 и 0. За пределами пула релевантность неизвестна. Результат относится к порядку уже найденных товаров и машинной оценке синтетических запросов. Полнота поиска по каталогу и удовлетворённость покупателей здесь не измерялись.

Из 99 168 попаданий исключены 10 записей со сбоем судьи. После нормализации ID и объединения списков осталось 63 199 оценённых пар запрос–товар до отбора запросов. Конфликтов между валидными оценками одного нормализованного ID внутри запроса не обнаружено. Из 1 259 строк исключены 28 совпадений с прежними выборками, 15 запросов с пулом меньше 20 и 29 повторов нормализованного текста. Для 44 из оставшихся 1 187 запросов все оценки в пуле нулевые. Они вошли в среднее с nDCG=0 по протоколу.

## Воспроизведение

Из общей рабочей папки на подготовленном Ubuntu-хосте:

```bash
tools/pc 'cd ~/search-depth && bash external-retail/reproduce.sh'
```

Скрипт проверяет контрольные суммы входов, запускает тесты, повторяет вывод модели и проверяет новые результаты в external-retail/replay. Для запуска непосредственно на машине с моделью из корня проекта достаточно команды `bash external-retail/reproduce.sh`. Нужны окружение из requirements.lock, study.py, data/model.onnx, data/tokenizer.json и сохранённый results/confirm/post.joblib. Список хешей прежних запросов приложен. Для проверки уже сохранённого результата без модели из search-pilot выполните `python3 external-retail/verify.py external-retail/results`.
