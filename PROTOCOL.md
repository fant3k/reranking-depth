# Confirmatory search experiment
Freeze before accessing official ESCI test scores. Only US English judged pools with at least 20 candidates. Exclude normalized query text from the fitted pilot and previously inspected WANDS sample. Score all remaining eligible official test queries. Train the same seeded random forest on the Amazon pilot training queries (reserve 200 for a median threshold); compare pre-call features against the existing post-ten-score router. Compare fixed 10, fixed 20, split 10+10, a deterministic random assignment with the same deep count, and best possible selection at that pair count. Oracle uses test labels for retrospective diagnosis only. Quality target: lower paired query-bootstrap bound of delta nDCG@10 vs full above -0.01. Timing target: reduce CPU p95 by 25% versus full and compare against the fastest eligible fixed baseline. Fixed seeds, one warm worker, fixed CPU threads, tokenization and routing included; initial retrieval excluded. Report queueing separately from service time. Load trace is synthetic. No test tuning. Per-query predictions, route decisions and timing samples saved for audit.
